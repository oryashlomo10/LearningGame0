# data/

- `questions.json` - 24 שאלות לדוגמה (מבוא למדעי המחשב). משמשות **רק במצב הדגמה**, כשאין שאלות מאושרות.
- `approved_questions.json` - שאלות שנוצרו מחומר לימוד שהמשתמש העלה ואושרו ידנית (נושא משחק, ציטוט מקור, מקטע, עמוד ומסמך נשמרים עם כל שאלה). מתחיל ריק. כשיש בו שאלות, המשחק משתמש **רק בהן**.
- `attempts.jsonl` - ניסיונות מענה של שחקנים אמיתיים בלבד (לאיסוף נתונים עתידי).

הבדיקות האוטומטיות לא נוגעות בקבצים האלה: הן משתמשות בקבצים זמניים.
